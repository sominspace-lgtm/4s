# 4S OS Internal Handbook

This handbook is the canonical product, design, engineering, and AI collaboration guide for **4S OS**.

4S OS stands for:

- **4Syl** — built for Sylvia, deeply personal at the origin.
- **SOS** — always there when life feels scattered.
- **Operating System** — not another productivity app, but a calm layer for organizing life.

## How to use this handbook with Claude

At the beginning of any serious Claude session, paste or reference:

1. `00-START-HERE-CLAUDE.md`
2. `01-CONSTITUTION.md`
3. `02-PROJECT-CONTEXT.md`
4. The specific chapter relevant to the task
5. `18-TASK-TEMPLATE.md`

For example, for login redesign, include:

- `00-START-HERE-CLAUDE.md`
- `01-CONSTITUTION.md`
- `02-PROJECT-CONTEXT.md`
- `05-UX-PRINCIPLES.md`
- `06-DESIGN-LANGUAGE.md`
- `15-AUTH-ENTRY-EXPERIENCE.md`
- `18-TASK-TEMPLATE.md`
