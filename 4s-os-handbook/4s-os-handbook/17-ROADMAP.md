# Roadmap

Roadmap items should be built only when they support the Constitution.

## Phase 0 — In-flight / finish first

1. Finish approved monochrome circular SOS Morse app icon everywhere. See `21-IN-FLIGHT-ICON-TASK.md`.
2. Verify with `npx tsc --noEmit` and `npx next build`.
3. Commit/push only when asked.

## Phase 1 — Make daily use excellent

1. Login / entry redesign
2. Mobile auth polish
3. Brief refinement
4. Better empty states
5. Human-readable auth and insert errors
6. Quick Capture polish
7. Search / command palette improvements
8. Consistent button hierarchy across screens
9. Weekly Review polish
10. Council card clarity

## Phase 2 — Deepen the OS

1. Guides replacing generic modes
2. Guide-specific Brief/Council microcopy
3. Energy Mode
4. Recovery Mode
5. Wins
6. Daily Reflection
7. Whispers
8. Relationship Memory MVP
9. Decision Memory MVP
10. Home Brain MVP

## Phase 3 — Invisible assistance

1. Life Autopilot
2. Friction Detection
3. Context Awareness
4. Better Refill Intelligence with real AI extraction
5. Shared With Me feed
6. Habit schedule editing
7. Push notifications as Whispers
8. Browser/share capture
9. Email/calendar intelligence

## Phase 4 — Ecosystem

1. Native mobile app or polished PWA-plus experience
2. Widgets
3. Watch companion
4. Voice capture
5. Alexa beta polish and smart assistant integration
6. Browser extension
7. Offline-first capture
8. Local-first AI where possible

## Always deprioritize

- dashboards for their own sake
- AI chat features without context
- gamification that creates anxiety
- social features that weaken privacy
- features that increase time spent in app
