# UX Principles

## One question per page

Every page exists to answer one question. If a page tries to answer five questions, split, hide, or simplify.

## Trust before action

Before asking a user to sign in, share, connect data, invite someone, or enable AI, explain why it helps and what remains private.

## Progressive disclosure

Show the next useful thing, not every possible thing.

Advanced controls should exist, but they should not be the default surface.

## Empty is a state, not a failure

Empty states should feel calm, not broken.

Examples:

- Queue clear. Protect your attention.
- Today has room to breathe.
- Nothing needs financial attention.
- Every important area has a home.

## No dead ends

Every empty state should offer exactly one gentle next step, unless the peaceful state is itself the point.

## Reduce typing

Typing is friction, especially on mobile.

Prefer:

- capture first, organize later
- smart defaults
- chips
- suggested dates
- swipe actions
- natural language capture

## Clear hierarchy

Every screen needs:

1. A clear title.
2. One primary action.
3. Quiet secondary actions.
4. Contextual help only when needed.

Do not make three actions visually equal.

## Calm feedback

4S OS should acknowledge progress without dopamine manipulation.

No loud confetti by default.

Prefer subtle language:

- Your queue is clear.
- You protected your attention.
- Seven-day rhythm.
- Reviewed.
- Ready.

## No guilt

Never punish the user for missing a habit, delaying a task, or returning after a long break.

Use:

- Worth revisiting.
- Ready when you are.
- Tomorrow is another opportunity.

Avoid:

- Failed.
- Streak broken.
- You missed.
- Overdue overload.

## Mobile first

If a feature is awkward on mobile, the feature is not done.

## The five-second test

For every important screen, a new user should understand within five seconds:

- where they are
- what this page does
- what the primary action is
- whether anything needs attention

## The one-minute test

For Brief, the user should understand what matters in under one minute.
